# Midtrans Overview

Overview of Midtrans payment integration.

## What is Midtrans?

Midtrans is a payment gateway service for Indonesia, providing various payment methods.

## Features

- Multiple payment methods
- Secure payment processing
- Webhook notifications
- Sandbox environment for testing

## Payment Methods

- Bank Transfer (BCA, BNI, BRI, Mandiri, Permata)
- Credit Card
- E-Wallet (GoPay, ShopeePay, Dana)
- Retail (Indomaret, Alfamart)

## Integration Points

- Create transaction
- Handle webhook
- Verify payment status

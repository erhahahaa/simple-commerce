# Resend Email

Email service integration.

## What is Resend?

Resend is a modern email API for transactional emails.

## Features

- Simple API
- React Email templates
- High deliverability
- Developer-friendly

## Use Cases

- Email verification
- Password reset
- Order confirmations

## Setup

1. Register at resend.com
2. Get API key
3. Add to environment variables

## Environment Variables

```env
RESEND_API_KEY=re_your_api_key
```

Email templates built with React components.

# Glossary

Terms and definitions used in Simple Commerce.

## A

**API (Application Programming Interface)** - Interface for communication between mobile app and backend.

**Authentication** - Process of verifying user identity.

## B

**Better Auth** - Authentication library used in the project.

**Bun** - JavaScript runtime used for the project.

## C

**Cart** - Shopping cart containing items user wants to purchase.

**Category** - Product classification (Electronics, Fashion, etc.).

**Checkout** - Process of completing a purchase.

**CORS (Cross-Origin Resource Sharing)** - Security feature for cross-origin requests.

## D

**Drizzle ORM** - TypeScript ORM for database operations.

## E

**Expo** - React Native development platform.

**Expo Router** - File-based routing for Expo.

## F

**Fast Refresh** - Hot reloading feature for React Native.

## H

**Hono** - Lightweight web framework for the backend.

**HeroUI** - UI component library for React Native.

## M

**Metro** - JavaScript bundler for React Native.

**Midtrans** - Payment gateway service.

**Monorepo** - Repository containing multiple packages/apps.

**Mutation** - Operation that modifies data (TanStack Query).

## O

**ORPC** - Type-safe RPC library for API communication.

**Order** - Customer purchase record.

## P

**Procedure** - ORPC endpoint definition (query or mutation).

**Protected Procedure** - ORPC endpoint requiring authentication.

## Q

**Query** - Operation that fetches data (TanStack Query).

## R

**Raja Ongkir** - Indonesian shipping cost calculation API.

**React Native** - Framework for building mobile apps.

## S

**Schema** - Database table structure definition.

**Session** - User authentication session.

**Shipping** - Delivery of orders to customers.

**Slug** - URL-friendly identifier (e.g., "electronics").

## T

**Tailwind CSS** - Utility-first CSS framework.

**TanStack Query** - Data fetching and caching library.

**Turborepo** - Monorepo task runner.

## W

**Webhook** - HTTP callback for event notifications.

**Workspace** - Package or app in a monorepo.

## Z

**Zod** - TypeScript schema validation library.

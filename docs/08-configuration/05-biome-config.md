# Biome Configuration

Code formatting and linting with Biome.

## File

`biome.json`

## Features

- Fast formatting (faster than Prettier)
- Linting rules
- Import organization
- TypeScript support

## Usage

```bash
# Format and lint
bun run check

# Fix issues
bun run check --write
```

## Configuration

Biome replaces both Prettier and ESLint with a single fast tool.

## IDE Integration

Install Biome extension for VS Code for real-time formatting.
